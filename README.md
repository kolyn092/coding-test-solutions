# 🧠 coding-test-solutions

> 문제 해결 능력 향상을 위한 알고리즘 풀이 저장소입니다.

---

## 📌 About

- 다양한 알고리즘 문제를 풀이하며
**문제 해결 과정과 사고 흐름을 기록**하는 것을 목표로 합니다.

---

## 🛠 Tech Stack

* Language: Java
* Tools: IntelliJ, Git

---

## 📂 Directory Structure

```
ps
 ├─ Level1
 |    └─ 문제 이름
 ├─ Level2
 └─ Level3
```

---

## ✏️ Problem Solving Convention

* 파일명: `문제 이름`
* 문제별 폴더 내 포함 내용:

  * ✔️ 문제 풀이 코드
  * ✔️ 풀이 접근 방법 (주석 또는 별도 md)
  * ✔️ 시간/공간 복잡도 분석

---

## 📝 Commit Convention

* 백준 [BOJ], 프로그래머스 [PGS]
* `[BOJ] xxx번 문제 - BFS / Silver 2`
* `[PGS] 타겟 넘버 - DFS / Level 2`
