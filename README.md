# 🧠 coding-test-solutions

> 문제 해결 능력 향상을 위한 알고리즘 풀이 저장소입니다.

---

## 📌 About

- 다양한 알고리즘 문제를 풀이하며
**문제 해결 과정과 사고 흐름을 기록**하는 것을 목표로 합니다.

---

## 🛠 Tech Stack

* Language: Java
* Tools: IntelliJ, Git

---

## 📂 Directory Structure

```
etc
 ├─ practice
 |     └─ ...
 └─ ps  
     ├─ Level1
     |    └─ 문제 이름
     └─ Level2  

프로그래머스
 ├─ 0
 |  └─문제 이름
 |       ├─ README.md
 |       └─ .java
 | 
 └─ 1 

```
* etc 폴더는 이전에 작업한 내용이거나 학습 목적으로 사용합니다.

* 이외의 폴더는 사이트에서 문제를 풀 경우 자동으로 commit되는 폴더들입니다.

---

## ✏️ Problem Solving Convention

* 폴더명: `문제번호. 문제이름`
* 문제별 폴더 내 포함 내용:

  * ✔️ 문제 풀이 코드 - 문제이름.java
  * ✔️ 문제 풀이 정보 - README.md

```
[level ?] Title: 문제 이름, Time: 걸린 시간(ms), Memory: 사용된 메모리 -BaekjoonHub
[PGS] 문제이름 / Level ?
[ETC] 알고리즘 이름 - 문제 이름
```
